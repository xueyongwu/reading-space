# 我的阅读空间

手机端个人读书工作台。纯 HTML + CSS + 原生 JavaScript，无需注册登录，不需要数据库，数据只保存在你自己手机的浏览器里。

## 功能

- **首页**：年度已读、正在阅读、笔记总数、年度阅读页数；阅读日历；最近阅读
- **书架**：添加 / 编辑 / 删除书籍（书名、作者、封面、分类、阅读状态），按状态和分类筛选
- **阅读进度**：总页数、已读页数、自动计算百分比和进度条；读到最后一页自动标记「已读」
- **读书笔记**：章节、摘录、个人感悟、行动建议、主题，可随时编辑删除
- **知识库**：汇总全部笔记，关键词搜索（高亮）、按主题筛选，显示笔记来源
- **数据**：JSON 导出 / 导入（覆盖或合并），导入和清空前自动保存快照，可以恢复

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 整个应用（页面、样式、逻辑都在这一个文件里） |
| `manifest.webmanifest` | 让手机把它当成 App 添加到主屏幕 |
| `sw.js` | 离线缓存，没网也能打开 |
| `icons/` | 主屏幕图标 |

## 统计口径

- **年度已读**：读完日期在今年的书。
- **年度阅读页数 / 阅读日历**：只统计通过「更新进度」记下的页数增量。
  - 添加或编辑书籍时直接填写的已读页数视为补录，不计入。
  - 页数往回改不会删除历史记录；之后再往前读，只有超过之前最高页数的部分才计入，不会重复计算。
  - 写笔记的那天在日历上会显示一个小圆点。
  - 不会自动生成任何打卡记录。
- 示例数据带有标记，「清空示例」只删除示例，不会删除你自己添加或修改过的内容。

## 放到手机上使用

1. 打开 GitHub Pages 网址（见下方「部署」）。
2. **iPhone**：用 Safari 打开 → 点底部「分享」→「添加到主屏幕」。**之后一律从主屏幕图标打开**。
   Safari 和主屏幕图标的数据是分开存的，所以要先添加到主屏幕再开始记录。
3. **安卓**：用 Chrome / Edge 打开 → 右上角菜单 →「添加到主屏幕」或「安装应用」。

## 备份数据

数据只在这台手机的这个浏览器里，以下情况会丢失：清除浏览器数据、无痕模式、卸载浏览器、换手机、网址变了。

- **导出**：首页右上角齿轮 →「数据与备份」
  - 「分享 / 存储到文件」：可以存到 iCloud、网盘，或者发给微信「文件传输助手」
  - 「下载文件」：保存到手机的下载目录
  - 「复制为文本」：粘贴到备忘录里保存
- **导入**：同一页面选择备份文件，或者粘贴文本；可选「覆盖」或「合并」。
- 超过 14 天没备份，首页会提醒。

## 从微信读书同步

微信读书没有开放接口。`tools/weread-sync.js` 在电脑浏览器里借用网页版的登录状态读取数据，生成同步文件，再导入工作台。

1. 电脑浏览器登录 https://weread.qq.com，**打开任意一本书进入阅读页**（划线只有在阅读页才读得到）。
2. 打开控制台（Mac：`Cmd + Option + J`；Windows：`F12`），粘贴 `tools/weread-sync.js` 的全部内容，回车。
   - 如果 Chrome 提示不允许粘贴，先按提示输入 `allow pasting`（中文版是「允许粘贴」）。
   - 如果页面卡在「Paused in debugger」（微信读书的反调试），按 `Cmd/Ctrl + F8` 停用断点，再按 `F8` 继续。
3. 左下角面板出结果后，点「下载同步文件」。
4. 把文件传到手机（AirDrop，或发到微信「文件传输助手」后「保存到文件」），在工作台「数据与备份 → 选择备份文件」里选它。

同步的内容和规则：

- 只同步「有进度、已读完或有划线」的书；书籍按**百分比**记录进度。
- 读完日期取微信读书的真实读完时间；没有读完时间的书不计入「年度已读」。
- 每条划线变成一条笔记（摘录 + 章节 + 划线时的真实日期），在日历上显示为笔记圆点。
- 同步**不生成阅读记录**：微信读书只有累计阅读时长，没有按天的数据，所以日历不会被同步刷出颜色；累计时长显示在书籍详情里。
- 按微信读书的编号对应，反复同步不会重复；书架上已有的同名书会被关联，不会再建一本。
- 已有的书只更新进度、读完状态和累计时长；你改过的书名、分类、封面和写的感悟都不会被覆盖。
- 删除过的书和划线，以后同步也不会再加回来。
- 同步前会自动保存快照，可以在「数据与备份」里恢复。

注意：脚本用的是微信读书网页版的非公开接口，只发读取请求，不修改微信读书里的内容。微信读书改版后脚本可能失效。

`tools/` 里的 `weread-probe*.js` 是摸索接口时用的只读探测脚本，平时用不到。

## 部署 / 更新

本仓库通过 GitHub Pages 发布（Settings → Pages → 从 `main` 分支根目录部署）。
修改后提交并推送，等一两分钟就会生效。如果改了 `sw.js` 里缓存的文件列表，记得把里面的 `VERSION` 加一。

本地预览：

```bash
python3 -m http.server 8790
# 浏览器打开 http://127.0.0.1:8790
```
